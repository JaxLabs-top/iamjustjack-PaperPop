# Paper Pop

**Torn paper, pastels, polaroids.** The React component library behind [iamjustjack.de](https://iamjustjack.de) - grown into a full kit for landing pages, dashboards, forums and apps.

- ~100 components, every one with its own doc page, props table, usage snippet and a rendered screenshot (or GIF when it moves)
- used as a **git submodule** - no npm publishing, no build step, full HMR
- an **MCP server** so Claude Code can look up components, props and page recipes while building
- docs, images and this README are **regenerated automatically** on every push (self-hosted runner)

Start a new site from **[PaperPop-Template](https://github.com/JaxLabs-top/PaperPop-Template)** - it already contains the submodule, example pages and the deploy setup.

## Quick start

```bash
git submodule add https://github.com/JaxLabs-top/iamjustjack-PaperPop.git paperpop
```

```ts
// vite.config.ts
import { paperpop } from './paperpop/vite';
export default defineConfig({ plugins: [react(), paperpop()] });
```

```tsx
// main.tsx
import 'paperpop/fonts';
import 'paperpop/styles.css';
import { Button, Paper } from 'paperpop';

<Paper color="lilac" tilt={-1}>
  <h1 className="pp-display">Hallo.</h1>
  <Button>Sag Hallo ♥</Button>
</Paper>
```

Full setup (tsconfig paths, fonts, CI token): [docs/guides/setup.md](docs/guides/setup.md)

## MCP server

`mcp/server.mjs` is a dependency-free MCP server (stdio). Add it to a site's `.mcp.json`:

```json
{ "mcpServers": { "paperpop": { "command": "node", "args": ["paperpop/mcp/server.mjs"] } } }
```

Tools: `list_components`, `search_components`, `get_component` (doc + props + source), `get_design_tokens`, `get_setup_guide`, `get_page_recipe`, `get_contributing_guide`. Every component doc is also a resource (`paperpop://components/<Name>`).

## Development

```bash
npm install
npm run dev          # gallery with every component on http://localhost:5190
npm run typecheck
npm run docs         # screenshots/GIFs + docs + README (needs `npx playwright install chromium`)
npm run docs:meta    # docs + README only, keeps existing images
npm run torn         # regenerate the extra torn-edge shapes
```

On every push to `main` the [Docs workflow](.github/workflows/docs.yml) renders everything inside a pinned Playwright container on the self-hosted runner and commits the result as `Update component docs [skip ci]`.
