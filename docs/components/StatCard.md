# StatCard

**Dashboard** · [all components](../../README.md#components) · animated

KPI card: label, counting number, delta arrow, icon and sparkline.

![StatCard](../media/stat-card.gif)

## Usage

```tsx
import { StatCard } from 'paperpop';

<div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fit, minmax(220px, 1fr))', gap: 24 }}>
  <StatCard label="Besucher heute" value={1284} delta={12.5} icon="users" trend={[4, 6, 5, 8, 7, 11, 13]} />
  <StatCard label="Umsatz" value={3920} suffix=" €" delta={-3.1} icon="trend" color="mint" />
  <StatCard label="Conversion" value={4.2} suffix="%" delta={0.8} icon="zap" color="pink" tilt={-1} />
</div>
```

## Props

### StatCard

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` * | `ReactNode` |  | Small caps label ("Besucher heute"). |
| `value` * | `number \| string` |  | The big number. Numbers count up, strings are shown as they are. |
| `prefix` | `string` |  | Unit or prefix, e.g. "€" (prefix) - use suffix for "%". |
| `suffix` | `string` |  |  |
| `delta` | `number` |  | Change vs. previous period in percent; positive = up (mint), negative = down (pink). |
| `deltaLabel` | `ReactNode` | `'vs. Vorwoche'` | Text after the delta. |
| `icon` | `IconName` |  | Icon in the corner. |
| `color` | `PaperColor` | `'butter'` | Accent colour for the icon badge. |
| `trend` | `number[]` |  | Trend line in the corner. |
| `tilt` | `number` | `0` | Rotation in degrees. |

Also accepts: `HTMLAttributes<HTMLDivElement>` (native attributes are passed through).

\* required
