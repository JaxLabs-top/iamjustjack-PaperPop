# Container

**Layout** · [all components](../../README.md#components)

Centered page column (max 1280px) with a 16px gutter on phones.

![Container](../media/container.png)

## Usage

```tsx
import { Container } from 'paperpop';

<Container max={600} style={{ outline: '2px dashed var(--pp-pink)', padding: 20 }}>
  Alles, was hier drin ist, bleibt schön mittig und maximal 600px breit.
</Container>
```

## Props

### Container

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `max` | `number \| string` | `1280` | Max width. |
| `as` | `ElementType` | `'div'` | Rendered element. |
