# Composer

**Forum** · [all components](../../README.md#components)

Reply box with live markdown formatting, toolbar, preview, character counter and send button.

![Composer](../media/composer.png)

## Usage

```tsx
import { useState } from 'react';
import { Composer } from 'paperpop';

function Example() {
  const [last, setLast] = useState('');
  return (
    <div style={{ display: 'grid', gap: 12 }}>
      <Composer user="Jack" onSubmit={(text) => setLast(text)} />
      {last && <small>Gesendet: {last}</small>}
    </div>
  );
}
```

## Notes

While you type, `**bold**`, `_italic_`, `` `code` `` and `[links](https://)` are formatted in place with the markers greyed out. The toolbar (and Ctrl/Cmd+B, Ctrl/Cmd+I) wraps the selection and keeps the cursor in the box so you can carry on typing; Ctrl/Cmd+Enter sends. The eye button shows the finished result.

## Props

### Composer

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `onSubmit` * | `(text: string) => void \| Promise<void>` |  | Called with the text. The box clears afterwards. |
| `placeholder` | `string` | `'Schreib was Nettes …'` | Placeholder. |
| `submitLabel` | `ReactNode` | `'Senden'` | Submit label. |
| `user` | `string` |  | Your name for the avatar. |
| `maxLength` | `number` | `2000` | Max characters. |

Also accepts: `Omit<HTMLAttributes<HTMLFormElement>, 'onSubmit'>` (native attributes are passed through).

\* required
