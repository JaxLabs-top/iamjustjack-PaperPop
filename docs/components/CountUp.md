# CountUp

**Dashboard** · [all components](../../README.md#components) · animated

Number that counts up on mount or when the value changes.

![CountUp](../media/count-up.gif)

## Usage

```tsx
import { CountUp } from 'paperpop';

<div className="pp-display" style={{ fontSize: 'clamp(32px, 8vw, 52px)', display: 'flex', flexWrap: 'wrap', gap: '10px 40px', whiteSpace: 'nowrap' }}>
  <CountUp value={110} suffix="+" />
  <CountUp value={98.6} decimals={1} suffix="%" />
  <CountUp value={4200} prefix="€ " />
</div>
```

## Props

### CountUp

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` * | `number` |  | Target number. |
| `duration` | `number` | `1200` | Animation length in ms. |
| `decimals` | `number` | `0` | Decimal places. |
| `prefix` | `string` |  | Text before / after the number, e.g. "€" or "%". |
| `suffix` | `string` |  |  |

Also accepts: `HTMLAttributes<HTMLSpanElement>` (native attributes are passed through).

\* required
