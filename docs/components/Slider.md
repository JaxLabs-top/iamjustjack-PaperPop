# Slider

**Forms** · [all components](../../README.md#components)

Range slider with a washi tape fill and a value tag.

![Slider](../media/slider.png)

## Usage

```tsx
import { useState } from 'react';
import { Slider } from 'paperpop';

function Example() {
  const [v, setV] = useState(64);
  return <Slider value={v} onChange={setV} format={(n) => `${n}%`} aria-label="Lautstärke" />;
}
```

## Props

### Slider

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` * | `number` |  | Current value (controlled). |
| `onChange` * | `(value: number) => void` |  | Called with the new number. |
| `min` | `number` | `0` | Minimum. |
| `max` | `number` | `100` | Maximum. |
| `showValue` | `boolean` | `true` | Show the value in a little tag next to the slider. |
| `format` | `(v: number) => ReactNode` |  | Format the shown value. |

Also accepts: `Omit<InputHTMLAttributes<HTMLInputElement>, 'type' \| 'onChange'>` (native attributes are passed through).

\* required
