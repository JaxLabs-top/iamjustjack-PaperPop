# Drawer

**Apps** · [all components](../../README.md#components) · animated

A sheet of paper sliding in from the side - filters, details, settings.

![Drawer](../media/drawer.gif)

## Usage

```tsx
import { useState } from 'react';
import { Button, Drawer, Switch } from 'paperpop';

function Example() {
  const [open, setOpen] = useState(false);
  return (
    <>
      <Button color="sky" icon="settings" onClick={() => setOpen(true)}>Einstellungen</Button>
      <Drawer open={open} onClose={() => setOpen(false)} title="Einstellungen">
        <div style={{ display: 'grid', gap: 16 }}>
          <Switch label="Benachrichtigungen" defaultChecked />
          <Switch label="Newsletter" />
          <Switch label="Sparkles beim Klicken" defaultChecked color="pink" />
        </div>
      </Drawer>
    </>
  );
}
```

## Props

### Drawer

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` * | `boolean` |  | Visible or not. |
| `onClose` * | `() => void` |  | Called on backdrop click, Escape or the close button. |
| `title` * | `ReactNode` |  | Heading. |
| `children` | `ReactNode` |  | Content. |
| `side` | `'left' \| 'right'` | `'right'` | Side. |
| `width` | `number` | `380` | Width in px. |
