# Marker

**Foundations** · [all components](../../README.md#components) · animated

Marks inline text with a highlighter, scribbled underline, circle, strike or washi tape - drawn in on view.

![Marker](../media/marker.gif)

## Usage

```tsx
import { Marker } from 'paperpop';

<p style={{ fontSize: 22, lineHeight: 2.2, margin: 0 }}>
  Ich bin <Marker>Entwickler</Marker>, baue <Marker variant="underline" color="pink">Webseiten</Marker> und
  {' '}<Marker variant="circle" color="sky">Apps</Marker>, war <Marker variant="strike">nie</Marker> ohne Pläne und
  {' '}<Marker variant="washi">klebe gern Tape</Marker> auf alles.
</p>
```

## Props

### Marker

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `color` | `PaperColor` | `'butter'` | Highlight colour. |
| `variant` | `'highlight' \| 'underline' \| 'circle' \| 'washi' \| 'strike'` | `'highlight'` | How the text is marked. |
| `onView` | `boolean` | `true` | Draw the mark when it scrolls into view (instead of immediately). |

Also accepts: `HTMLAttributes<HTMLSpanElement>` (native attributes are passed through).

\* required
