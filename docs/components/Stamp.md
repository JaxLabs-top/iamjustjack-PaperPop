# Stamp

**Foundations** · [all components](../../README.md#components) · animated

Rubber stamp that thumps onto the page - success states, "sent!", "sold out".

![Stamp](../media/stamp.gif)

## Usage

```tsx
import { useState } from 'react';
import { Stamp } from 'paperpop';

function Example() {
  const [sent, setSent] = useState(false);
  return (
    <div style={{ position: 'relative', display: 'grid', placeItems: 'center', minHeight: 180 }}>
      <button type="button" className="pp-btn" onClick={() => setSent((s) => !s)}>Abschicken ♥</button>
      <Stamp overlay show={sent} note="ich melde mich bei dir ♥">Angekommen!</Stamp>
    </div>
  );
}
```

## Props

### Stamp

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `color` | `PaperColor` | `'butter'` | Stamp ink colour. |
| `tilt` | `number` | `-12` | Rotation in degrees. |
| `note` | `ReactNode` |  | Small handwritten line under the stamp text. |
| `show` | `boolean` | `true` | Controls visibility; toggling it to true plays the "thump" animation. |
| `overlay` | `boolean` |  | Center it absolutely over the parent (like a "sent!" overlay). |

Also accepts: `HTMLAttributes<HTMLDivElement>` (native attributes are passed through).

\* required
