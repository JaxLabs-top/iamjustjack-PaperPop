# LogoCloud

**Landing** · [all components](../../README.md#components)

"Known from" row with image logos or label-maker text tags.

![LogoCloud](../media/logo-cloud.png)

## Usage

```tsx
import { LogoCloud } from 'paperpop';

<LogoCloud logos={[{ name: 'Minecraft' }, { name: 'GitHub' }, { name: 'Discord' }, { name: 'Docker' }]} />
```

## Props

### LogoCloud

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `ReactNode` | `'bekannt aus'` | Handwritten label. |
| `logos` * | `Array<{ name: string; src?: string }>` |  | Logos: image URLs or text names (rendered as label-maker tags). |

Also accepts: `HTMLAttributes<HTMLDivElement>` (native attributes are passed through).

\* required
