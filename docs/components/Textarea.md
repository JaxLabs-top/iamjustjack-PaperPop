# Textarea

**Forms** · [all components](../../README.md#components)

Multi-line input that writes on ruled notebook lines.

![Textarea](../media/textarea.png)

## Usage

```tsx
import { Textarea } from 'paperpop';

<Textarea placeholder="Hey Jack, …" defaultValue={'Hey Jack,\nich hätte da eine Idee …'} />
```

## Props

### Textarea

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `ruled` | `boolean` | `true` | Ruled notebook lines behind the text. |

Also accepts: `TextareaHTMLAttributes<HTMLTextAreaElement>` (native attributes are passed through).
