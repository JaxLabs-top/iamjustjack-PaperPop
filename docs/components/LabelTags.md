# LabelTags

**Foundations** · [all components](../../README.md#components)

Label-maker (Dymo) tags for skills, tools and categories.

![LabelTags](../media/label-tags.png)

## Usage

```tsx
import { LabelTags } from 'paperpop';

<div style={{ display: 'grid', gap: 26 }}>
  <LabelTags items={['TypeScript', 'React', 'Swift', 'Docker', 'Minecraft', 'Prisma']} />
  <LabelTags size="sm" items={[{ label: 'neu', color: 'mint' }, { label: 'beliebt', color: 'pink' }, { label: 'beta', color: 'ink' }]} />
</div>
```

## Props

### LabelTags

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` * | `LabelTag[]` |  | Tags as strings or objects with colour/tilt. Colours cycle through the palette by default. |
| `size` | `'sm' \| 'md'` | `'md'` | Tag size. |

Also accepts: `HTMLAttributes<HTMLUListElement>` (native attributes are passed through).

\* required
