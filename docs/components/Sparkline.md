# Sparkline

**Dashboard** · [all components](../../README.md#components)

Tiny inline trend line for cards and tables.

![Sparkline](../media/sparkline.png)

## Usage

```tsx
import { Sparkline } from 'paperpop';

<div style={{ display: 'flex', flexWrap: 'wrap', gap: 30, alignItems: 'center' }}>
  <Sparkline values={[3, 5, 4, 8, 6, 9, 12]} />
  <Sparkline values={[12, 9, 10, 7, 8, 4, 3]} color="pink" />
  <Sparkline values={[5, 5, 6, 5, 7, 6, 8]} color="sky" width={160} area={false} />
</div>
```

## Props

### Sparkline

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `values` * | `number[]` |  | Data points. |
| `width` | `number` | `120` | Width in px. |
| `height` | `number` | `36` | Height in px. |
| `color` | `string` | `'ink'` | Line colour (palette name or CSS colour). |
| `area` | `boolean` | `true` | Soft area fill under the line. |

Also accepts: `Omit<HTMLAttributes<HTMLSpanElement>, 'color'>` (native attributes are passed through).

\* required
