# VoteButtons

**Forum** · [all components](../../README.md#components) · animated

Up/down voting with a bouncy score, vertical or horizontal.

![VoteButtons](../media/vote-buttons.gif)

## Usage

```tsx
import { VoteButtons } from 'paperpop';

<div style={{ display: 'flex', flexWrap: 'wrap', gap: 40, alignItems: 'center' }}>
  <VoteButtons score={41} />
  <VoteButtons score={7} horizontal />
</div>
```

## Props

### VoteButtons

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `score` * | `number` |  | Score before the user's own vote. |
| `vote` | `-1 \| 0 \| 1` |  | The user's vote (controlled). Leave undefined to let the component manage it. |
| `onVote` | `(vote: -1 \| 0 \| 1) => void` |  | Called with the new vote. |
| `horizontal` | `boolean` |  | Horizontal layout. |

Also accepts: `Omit<HTMLAttributes<HTMLDivElement>, 'onChange'>` (native attributes are passed through).

\* required
