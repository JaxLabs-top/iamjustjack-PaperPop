# TitleTypewriter

**Foundations** · [all components](../../README.md#components) · animated

Types the browser tab title: the old one is deleted back to the shared beginning, the new one is typed out.

![TitleTypewriter](../media/title-typewriter.gif)

## Usage

```tsx
import { useState, useEffect } from 'react';
import { Paper, Polaroid, TitleTypewriter, Washi } from 'paperpop';

function Example() {
  const pages = ['Paper Pop - Paper', 'Paper Pop - Polaroid', 'Paper Pop - Washi'];
  const [i, setI] = useState(-1);
  const [tab, setTab] = useState('');
  useEffect(() => {
    const read = () => setTab(document.title);
    read();
    const obs = new MutationObserver(read);
    obs.observe(document.head, { childList: true, characterData: true, subtree: true });
    return () => obs.disconnect();
  }, []);
  return (
    <div style={{ display: 'grid', gap: 18, justifyItems: 'start' }}>
      <TitleTypewriter title={pages[i]} />
      <div className="pp-display" style={{ padding: '8px 16px', border: '2.5px solid var(--pp-ink)', borderRadius: '10px 10px 0 0', background: 'var(--pp-paper)', minWidth: 300 }}>{tab || '\u00a0'}</div>
      <button className="pp-btn" onClick={() => setI((n) => (n + 1) % pages.length)}>Nächste Seite</button>
    </div>
  );
}
```

## Notes

Mount once at the app root. Pass `title` to set it directly, or leave it out to animate titles that a framework sets (e.g. Next metadata) - the whole `<head>` is observed because frameworks replace the `<title>` element. Plain function: `installTitleTypewriter(options)` returns an uninstall function. Background tabs and `prefers-reduced-motion` skip the animation.

## Props

### TitleTypewriter

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `string` |  | Sets the tab title (and types it). Leave out to animate titles set elsewhere, e.g. by a framework's metadata. |
| `deleteSpeed` | `number` | `22` | Milliseconds per deleted character. |
| `typeSpeed` | `number` | `42` | Milliseconds per typed character. |
| `cursor` | `string` | `'▌'` | Block shown at the end while the title moves. Empty string for none. |
| `settle` | `number` | `150` | Milliseconds the title must stay unchanged before typing starts, so quick successive changes only animate the last one. |

\* required
