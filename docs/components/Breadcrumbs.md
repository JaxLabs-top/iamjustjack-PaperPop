# Breadcrumbs

**Navigation** · [all components](../../README.md#components)

Path navigation with handwritten arrows; the current page gets a label.

![Breadcrumbs](../media/breadcrumbs.png)

## Usage

```tsx
import { Breadcrumbs } from 'paperpop';

<Breadcrumbs items={[{ label: 'Forum', href: '/forum' }, { label: 'Hilfe', href: '/forum/help' }, { label: 'Server startet nicht' }]} />
```

## Props

### Breadcrumbs

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` * | `Array<{ label: ReactNode; href?: string }>` |  | Path items; the last one is the current page. |

Also accepts: `HTMLAttributes<HTMLElement>` (native attributes are passed through).

\* required
