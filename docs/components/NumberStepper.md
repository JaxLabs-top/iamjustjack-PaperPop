# NumberStepper

**Forms** · [all components](../../README.md#components) · animated

Minus / value / plus for quantities - click the number to type one.

![NumberStepper](../media/number-stepper.gif)

## Usage

```tsx
import { useState } from 'react';
import { NumberStepper } from 'paperpop';

function Example() {
  const [n, setN] = useState(1);
  return <NumberStepper value={n} onChange={setN} min={0} max={9} />;
}
```

## Props

### NumberStepper

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` * | `number` |  | Current value. |
| `onChange` * | `(value: number) => void` |  | Called with the new value. |
| `min` | `number` | `0` | Minimum. |
| `max` | `number` | `Infinity` | Maximum. |
| `step` | `number` | `1` | Step size. |
| `label` | `string` | `'Anzahl'` | Accessible label. |

Also accepts: `Omit<HTMLAttributes<HTMLDivElement>, 'onChange'>` (native attributes are passed through).
