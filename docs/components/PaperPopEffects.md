# PaperPopEffects

**Foundations** · [all components](../../README.md#components) · animated

Page effects: sparkles on every click and washi tape text selection. Mount once at the app root.

![PaperPopEffects](../media/paper-pop-effects.gif)

## Usage

```tsx
import { PaperPopEffects, StickyNote } from 'paperpop';

<div style={{ display: 'grid', placeItems: 'center', minHeight: 160 }}>
  <PaperPopEffects />
  <StickyNote color="butter" hand>Klick irgendwo hin ✦ und markier mal Text.</StickyNote>
</div>
```

## Notes

Also available as plain functions: `installSparkles()`, `installWashiSelection()` (both return an uninstall function) and `burstSparkles(x, y)`. Everything respects `prefers-reduced-motion`.

## Props

### PaperPopEffects

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `sparkles` | `boolean` | `true` | Sparkles on every click. |
| `washiSelection` | `boolean` | `true` | Washi tape text selection on desktop. |

\* required
