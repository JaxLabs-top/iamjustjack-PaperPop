# FileDrop

**Forms** · [all components](../../README.md#components)

Dashed drop zone: click or drag files onto it, chosen files appear as removable previews.

![FileDrop](../media/file-drop.png)

## Usage

```tsx
import { FileDrop } from 'paperpop';

<FileDrop accept="image/*" multiple onFiles={(files) => console.log(files)} />
```

## Props

### FileDrop

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `onFiles` * | `(files: File[]) => void` |  | Called with the chosen or dropped files. |
| `accept` | `string` |  | accept attribute of the hidden input, e.g. "image/*". |
| `multiple` | `boolean` |  | Allow several files. |
| `title` | `ReactNode` | `'Datei hier ablegen'` | Main text. |
| `hint` | `ReactNode` | `'oder klicken zum Auswählen'` | Small text under the title. |

Also accepts: `Omit<HTMLAttributes<HTMLLabelElement>, 'onChange' \| 'onDrop' \| 'title'>` (native attributes are passed through).

\* required
