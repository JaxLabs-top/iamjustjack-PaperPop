# Progress

**Feedback** · [all components](../../README.md#components) · animated

Progress bar filled with rolling washi tape, or indeterminate while loading.

![Progress](../media/progress.gif)

## Usage

```tsx
import { Progress } from 'paperpop';

<div style={{ display: 'grid', gap: 22 }}>
  <Progress value={68} label="Profil vollständig" />
  <Progress value={35} fill="mint" label="Speicher" />
  <Progress label="Lädt hoch …" showValue={false} />
</div>
```

## Props

### Progress

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number` |  | 0 - 100. Leave undefined for an indeterminate bar. |
| `label` | `ReactNode` |  | Visible label above the bar. |
| `showValue` | `boolean` | `true` | Show the percentage on the right. |
| `fill` | `'washi' \| PaperColor` | `'washi'` | Fill style. |

Also accepts: `HTMLAttributes<HTMLDivElement>` (native attributes are passed through).

\* required
