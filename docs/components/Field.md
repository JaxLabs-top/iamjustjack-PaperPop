# Field

**Forms** · [all components](../../README.md#components)

Label, input and hint/error in one - wires id and aria attributes automatically.

![Field](../media/field.png)

## Usage

```tsx
import { Field, Input } from 'paperpop';

<div style={{ display: 'grid', gap: 24 }}>
  <Field label="Name" required hint="So, wie ich dich nennen soll.">
    <Input placeholder="z.B. Kim" />
  </Field>
  <Field label="E-Mail" error="Das sieht nicht nach einer E-Mail aus.">
    <Input variant="box" defaultValue="kim@" />
  </Field>
</div>
```

## Props

### Field

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` * | `ReactNode` |  | Label text (small caps above the input). |
| `hint` | `ReactNode` |  | Helper text under the input. |
| `error` | `ReactNode` |  | Error message - replaces the hint and marks the input invalid. |
| `required` | `boolean` |  | Adds a pink asterisk to the label. |

Also accepts: `HTMLAttributes<HTMLDivElement>` (native attributes are passed through).

\* required
