# Navbar

**Navigation** · [all components](../../README.md#components)

Top bar with brand and pill links; turns into a menu button on phones.

![Navbar](../media/navbar.png)

## Usage

```tsx
import { Button, Navbar } from 'paperpop';

<Navbar
  brand="jack"
  links={[
    { label: 'der name', href: '#name', active: true },
    { label: 'projekte', href: '#projects' },
    { label: 'hallo sagen', href: '#contact' },
  ]}
  actions={<Button size="sm" color="butter">Login</Button>}
  style={{ padding: 0 }}
/>
```

## Props

### Navbar

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `brand` * | `ReactNode` |  | Brand text ("jack"). A pink dot is added after it. |
| `brandHref` | `string` | `'/'` | Brand link. |
| `links` | `NavLink[]` |  | Navigation pills. |
| `actions` | `ReactNode` |  | Extra content on the right (buttons, avatar). |
| `sticky` | `boolean` |  | Stick to the top while scrolling. |
| `collapse` | `boolean` | `true` | Fold the links into a menu button on phones. With false the pills just wrap. |
| `back` | `{ label: ReactNode; href: string }` |  | Sub-page mode: a back pill on the left, the brand moves to the right. |

Also accepts: `HTMLAttributes<HTMLElement>` (native attributes are passed through).

\* required
