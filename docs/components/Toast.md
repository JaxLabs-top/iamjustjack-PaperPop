# Toast

**Feedback** · [all components](../../README.md#components) · animated

Little notes that slide in from the corner. Wrap the app in ToastProvider, then call useToast().

![Toast](../media/toast.gif)

## Usage

```tsx
import { Pill, Toast, useToast } from 'paperpop';

function Example() {
  const toast = useToast();
  return (
    <div style={{ display: 'flex', gap: 14, flexWrap: 'wrap', alignItems: 'center' }}>
      <Pill onClick={() => toast({ title: 'Gespeichert!', description: 'Deine Änderungen sind sicher.' })}>Erfolg</Pill>
      <Pill onClick={() => toast({ title: 'Upload fehlgeschlagen', description: 'Datei ist größer als 10 MB.', status: 'error' })}>Fehler</Pill>
      <Toast title="Einzeln nutzbar" description="auch ohne Provider" status="info" />
    </div>
  );
}
```

## Notes

```tsx
// main.tsx
<ToastProvider position="bottom-right"><App /></ToastProvider>

// anywhere
const toast = useToast();
toast({ title: 'Gespeichert!', description: 'Alles sicher.', status: 'success' });
```
