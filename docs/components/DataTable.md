# DataTable

**Dashboard** · [all components](../../README.md#components)

Sortable table with sticky header, zebra rows, custom cells and an empty state.

![DataTable](../media/data-table.png)

## Usage

```tsx
import { Avatar, Badge, DataTable } from 'paperpop';

<DataTable
  rows={[
    { name: 'Boby', plan: 'Pro', posts: 342, status: 'aktiv' },
    { name: 'Kim', plan: 'Free', posts: 128, status: 'aktiv' },
    { name: 'Alex', plan: 'Team', posts: 57, status: 'pausiert' },
  ]}
  columns={[
    { key: 'name', header: 'Name', sortable: true, render: (r) => <span style={{ display: 'inline-flex', gap: 10, alignItems: 'center' }}><Avatar name={r.name} size="sm" />{r.name}</span> },
    { key: 'plan', header: 'Plan', sortable: true },
    { key: 'posts', header: 'Beiträge', sortable: true, align: 'right' },
    { key: 'status', header: 'Status', render: (r) => <Badge color={r.status === 'aktiv' ? 'mint' : 'butter'}>{r.status}</Badge> },
  ]}
/>
```

## Props

### DataTable

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `columns` * | `Column<T>[]` |  | Column definitions. |
| `rows` * | `T[]` |  | Rows. |
| `rowKey` | `(row: T) => string \| number` | `row index` | Unique key per row. |
| `onRowClick` | `(row: T) => void` |  | Row click handler (makes rows look clickable). |
| `empty` | `ReactNode` | `'Noch nichts da.'` | Shown when rows is empty. |
| `dense` | `boolean` |  | Compact rows. |

Also accepts: `HTMLAttributes<HTMLDivElement>` (native attributes are passed through).

\* required
