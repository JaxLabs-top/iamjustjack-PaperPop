# Sticker

**Foundations** · [all components](../../README.md#components) · animated

Round, burst or star sticker for "NEU!" labels - wiggles on hover or spins slowly.

![Sticker](../media/sticker.gif)

## Usage

```tsx
import { Sticker } from 'paperpop';

<div style={{ display: 'flex', flexWrap: 'wrap', gap: 40, alignItems: 'center' }}>
  <Sticker shape="burst" color="butter">Neu!</Sticker>
  <Sticker shape="circle" color="pink" size={110} tilt={-10}>-20%</Sticker>
  <Sticker shape="star" color="mint" size={120}>Top</Sticker>
  <Sticker shape="circle" color="sky" spin>Hi!</Sticker>
</div>
```

## Props

### Sticker

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `color` | `Tone` | `'butter'` | Sticker colour. |
| `shape` | `'circle' \| 'burst' \| 'star'` | `'burst'` | Outline shape. |
| `size` | `number` | `96` | Diameter in px. |
| `tilt` | `number` | `12` | Rotation in degrees. |
| `spin` | `boolean` |  | Spin slowly all the time instead of only on hover. |

Also accepts: `HTMLAttributes<HTMLSpanElement>` (native attributes are passed through).

\* required
