# FeatureGrid

**Landing** · [all components](../../README.md#components)

Grid of torn feature cards with icon stickers, alternating colours and tilts.

![FeatureGrid](../media/feature-grid.png)

## Usage

```tsx
import { FeatureGrid } from 'paperpop';

<FeatureGrid items={[
  { icon: 'zap', title: 'Schnell gebaut', text: 'Komponenten zusammenstecken, fertig ist die Seite.' },
  { icon: 'heart', title: 'Mit Liebe', text: 'Jedes Detail ein bisschen schief - mit Absicht.' },
  { icon: 'shield', title: 'Kein Tracking', text: 'Keine Cookies, keine Werbung, keine Tricks.' },
]} />
```

## Props

### FeatureGrid

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` * | `Feature[]` |  | Features. Colours and tilts vary automatically. |
| `columns` | `number` | `3` | Columns on wide screens. |

Also accepts: `HTMLAttributes<HTMLDivElement>` (native attributes are passed through).

\* required
