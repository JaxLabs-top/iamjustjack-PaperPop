# ConsentBanner

**Feedback** · [all components](../../README.md#components) · animated

Cookie/consent sticky note in the corner with a dimmed page - you decide where the choice is stored.

![ConsentBanner](../media/consent-banner.gif)

## Usage

```tsx
import { useState } from 'react';
import { ConsentBanner, Pill } from 'paperpop';

function Example() {
  const [open, setOpen] = useState(false);
  return (
    <>
      <Pill onClick={() => setOpen(true)}>Cookie-Einstellungen</Pill>
      <ConsentBanner open={open} onAccept={() => setOpen(false)} onDecline={() => setOpen(false)}>
        <p>Kein Tracking, keine Werbung. Nur fürs Kontaktformular lade ich <strong>Cloudflare Turnstile</strong>.</p>
      </ConsentBanner>
    </>
  );
}
```

## Props

### ConsentBanner

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` * | `boolean` |  | Show the banner. |
| `title` | `ReactNode` | `'Kurz was Rechtliches.'` | Heading. |
| `children` * | `ReactNode` |  | Explanation text. |
| `acceptLabel` | `ReactNode` | `'Passt ♥'` | Accept button label. |
| `declineLabel` | `ReactNode` | `'Nur notwendige'` | Decline button label. |
| `onAccept` * | `() => void` |  | Accept handler. |
| `onDecline` * | `() => void` |  | Decline handler. |
| `backdrop` | `boolean` | `true` | Dim the page behind the banner. |
| `status` | `ReactNode` |  | Small line under the buttons, e.g. the current choice. |

\* required
