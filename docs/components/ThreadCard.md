# ThreadCard

**Forum** · [all components](../../README.md#components)

Forum thread in a list: votes, category, title, excerpt, tags, participants and counters.

![ThreadCard](../media/thread-card.png)

## Usage

```tsx
import { ThreadCard } from 'paperpop';

<div style={{ display: 'grid', gap: 18 }}>
  <ThreadCard pinned title="Willkommen! Bitte zuerst lesen" href="#t1" author="Jack" time="vor 3 Tagen" category={{ label: 'Ankündigung', color: 'pink' }} replies={24} views={1200} />
  <ThreadCard score={42} solved title="Server startet nach Update nicht mehr" href="#t2" author="Kim" time="vor 2 Std."
    excerpt="Seit dem Update auf 1.21 hängt der Start bei Loading libraries. Hat jemand eine Idee, woran das liegen kann?"
    category={{ label: 'Hilfe', color: 'sky' }} tags={['paper', 'plugins']} replies={8} views={214} participants={['Boby', 'Alex', 'Sam']} />
</div>
```

## Props

### ThreadCard

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `title` * | `ReactNode` |  | Thread title. |
| `href` | `string` |  | Link to the thread. |
| `author` * | `string` |  | Author name. |
| `time` * | `ReactNode` |  | Relative time ("vor 2 Std."). |
| `excerpt` | `ReactNode` |  | Short preview of the first post. |
| `category` | `{ label: string; color?: Tone }` |  | Category chip. |
| `tags` | `string[]` |  | Tags under the excerpt. |
| `replies` | `number` |  | Reply count. |
| `views` | `number` |  | View count. |
| `score` | `number` |  | Vote score - shows a vote column when set. |
| `pinned` | `boolean` |  | Pinned threads get a pushpin. |
| `solved` | `boolean` |  | Marked solved/answered. |
| `participants` | `string[]` |  | People who replied (avatars). |

Also accepts: `Omit<HTMLAttributes<HTMLElement>, 'title'>` (native attributes are passed through).

\* required
