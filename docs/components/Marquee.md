# Marquee

**Landing** · [all components](../../README.md#components) · animated

Endless strip of tape with scrolling words - between sections or as a ticker.

![Marquee](../media/marquee.gif)

## Usage

```tsx
import { Marquee } from 'paperpop';

<div style={{ display: 'grid', gap: 30, overflow: 'hidden', padding: '10px 0' }}>
  <Marquee items={['Webseiten', 'Apps', 'Server', 'Minecraft', 'Design']} speed={12} />
  <Marquee items={['kein Tracking', 'selbst gehostet', 'mit Liebe gebaut']} color="washi" tilt={1.5} reverse speed={12} />
</div>
```

## Props

### Marquee

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` * | `ReactNode[]` |  | Items that scroll by, separated by sparkles. |
| `speed` | `number` | `24` | Seconds per loop. |
| `color` | `PaperColor \| 'washi'` | `'butter'` | Tape style background. |
| `tilt` | `number` | `-2` | Rotation in degrees. |
| `reverse` | `boolean` |  | Scroll right-to-left (default) or reverse. |

Also accepts: `HTMLAttributes<HTMLDivElement>` (native attributes are passed through).

\* required
