# CopyButton

**Buttons** · [all components](../../README.md#components) · animated

Copies text to the clipboard and flips to "Kopiert!" for two seconds.

![CopyButton](../media/copy-button.gif)

## Usage

```tsx
import { CopyButton } from 'paperpop';

<CopyButton text="curl -L iamjustjack.de" label="Befehl kopieren" />
```

## Props

### CopyButton

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `text` * | `string` |  | Text that goes to the clipboard. |
| `label` | `ReactNode` | `'Kopieren'` | Label before copying. |
| `done` | `ReactNode` | `'Kopiert!'` | Label after copying. |
| `onCopied` | `() => void` |  | Called after a successful copy. |

Also accepts: `Omit<ButtonHTMLAttributes<HTMLButtonElement>, 'onCopy'>` (native attributes are passed through).

\* required
