# Grid

**Layout** · [all components](../../README.md#components)

Responsive grid: fixed columns that collapse on small screens, or auto-fit by min width.

![Grid](../media/grid.png)

## Usage

```tsx
import { Card, Grid } from 'paperpop';

<Grid cols={3} gap={20}>
  {['pink', 'butter', 'mint', 'sky', 'lilac', 'paper'].map((c) => <Card key={c} color={c as 'pink'} pad={16}>{c}</Card>)}
</Grid>
```

## Props

### Grid

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `cols` | `number` |  | Fixed number of columns, or omit and use `min` for auto-fit. |
| `min` | `number \| string` | `240` | Minimum column width for auto-fit (number = px). |
| `gap` | `number \| string` | `30` | Gap (number = px). |
| `as` | `ElementType` | `'div'` | Rendered element. |

Also accepts: `HTMLAttributes<HTMLElement>` (native attributes are passed through).

\* required
