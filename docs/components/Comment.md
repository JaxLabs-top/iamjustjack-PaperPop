# Comment

**Forum** · [all components](../../README.md#components)

Threaded comments with a dashed reply line - nest Comments as children.

![Comment](../media/comment.png)

## Usage

```tsx
import { Comment } from 'paperpop';

<Comment author="Kim" time="vor 1 Std." text="Hat bei mir auch geholfen, danke!" likes={3} onReply={() => {}} op>
  <Comment author="Boby" time="vor 50 Min." text="Gern! Sag Bescheid, wenn noch was ist." likes={1} onReply={() => {}}>
    <Comment author="Kim" time="vor 45 Min." text="Läuft alles ♥" op />
  </Comment>
</Comment>
```

## Props

### Comment

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `author` * | `string` |  | Author name. |
| `time` * | `ReactNode` |  | Relative time. |
| `text` * | `ReactNode` |  | Comment text. |
| `likes` | `number` |  | Like count. |
| `children` | `ReactNode` |  | Nested replies (more &lt;Comment>s). |
| `onReply` | `() => void` |  | Called when "Antworten" is clicked. |
| `op` | `boolean` |  | Mark comments by the thread author. |

Also accepts: `HTMLAttributes<HTMLDivElement>` (native attributes are passed through).

\* required
