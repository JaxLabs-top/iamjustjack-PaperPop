# Heatmap

**Dashboard** · [all components](../../README.md#components)

Contribution-style calendar heatmap with five levels.

![Heatmap](../media/heatmap.png)

## Usage

```tsx
import { Heatmap } from 'paperpop';

<Heatmap values={Array.from({ length: 26 * 7 }, (_, i) => Math.round(Math.abs(Math.sin(i * 1.7) * 6 + Math.cos(i / 9) * 4)) - 2)} />
```

## Props

### Heatmap

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `values` * | `number[]` |  | Values per day, oldest first. Rendered in columns of 7 (weeks). |
| `color` | `PaperColor` | `'pink'` | Colour scale. |
| `legend` | `[string, string]` | `'weniger / mehr'` | Label for the legend. |
| `cell` | `number` | `14` | Cell size in px. |

Also accepts: `HTMLAttributes<HTMLDivElement>` (native attributes are passed through).

\* required
