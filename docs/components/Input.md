# Input

**Forms** · [all components](../../README.md#components)

Text input: ink underline on paper ("line") or a bordered box for apps ("box").

![Input](../media/input.png)

## Usage

```tsx
import { Input } from 'paperpop';

<div style={{ display: 'grid', gap: 24 }}>
  <Input placeholder="line: du@irgendwo.de" type="email" />
  <Input variant="box" placeholder="box: Projektname" />
</div>
```

## Props

### Input

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'line' \| 'box'` | `'line'` | Look of the input: underlined (on paper) or boxed (in apps/dashboards). |

Also accepts: `InputHTMLAttributes<HTMLInputElement>` (native attributes are passed through).

\* required
