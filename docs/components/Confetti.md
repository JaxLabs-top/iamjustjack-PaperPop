# Confetti

**Foundations** · [all components](../../README.md#components) · animated

Paper confetti burst - fire it on success moments by changing a counter.

![Confetti](../media/confetti.gif)

## Usage

```tsx
import { useState } from 'react';
import { Confetti } from 'paperpop';

function Example() {
  const [fire, setFire] = useState(0);
  return (
    <div style={{ display: 'grid', placeItems: 'center', minHeight: 220, position: 'relative' }}>
      <button type="button" className="pp-btn pp-c-butter" onClick={() => setFire((n) => n + 1)}>
        Geschafft!
        <Confetti fire={fire} />
      </button>
    </div>
  );
}
```

## Notes

Imperative version: `burstConfetti(x, y, count)` with viewport coordinates.

## Props

### Confetti

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `fire` * | `number` |  | Change this value (e.g. increment a counter) to fire another burst. 0 never fires. |
| `count` | `number` | `28` | Pieces per burst. |

\* required
