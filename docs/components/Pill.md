# Pill

**Buttons** · [all components](../../README.md#components) · animated

Outlined rounded secondary button for navigation, filters and secondary actions.

![Pill](../media/pill.gif)

## Usage

```tsx
import { Pill } from 'paperpop';

<div style={{ display: 'flex', gap: 12, flexWrap: 'wrap', alignItems: 'center' }}>
  <Pill href="#" active>der name</Pill>
  <Pill href="#">projekte</Pill>
  <Pill icon="filter" color="mint">Filter</Pill>
  <Pill small color="butter">klein</Pill>
  <Pill disabled>aus</Pill>
</div>
```

## Props

### Pill

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `active` | `boolean` |  | Marks the pill as selected / current page. |
| `color` | `PaperColor` | `'pink'` | Colour when hovered or active. |
| `icon` | `IconName` |  | Icon before the label. |
| `small` | `boolean` |  | Compact version. |

Also accepts: `Clickable` (native attributes are passed through).

\* required
