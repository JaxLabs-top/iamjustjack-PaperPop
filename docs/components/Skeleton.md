# Skeleton

**Feedback** · [all components](../../README.md#components) · animated

Shimmering placeholders while content loads.

![Skeleton](../media/skeleton.gif)

## Usage

```tsx
import { Skeleton } from 'paperpop';

<div style={{ display: 'grid', gridTemplateColumns: 'auto 1fr', gap: 16, alignItems: 'center' }}>
  <Skeleton circle width={56} />
  <Skeleton lines={3} />
</div>
```

## Props

### Skeleton

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `width` | `number \| string` | `'100%'` | Width (number = px). |
| `height` | `number \| string` | `16` | Height (number = px). |
| `circle` | `boolean` |  | Round (avatars). |
| `lines` | `number` |  | Render n text lines instead of one block. |

Also accepts: `HTMLAttributes<HTMLSpanElement>` (native attributes are passed through).
