# Notebook

**Foundations** · [all components](../../README.md#components)

Ruled notebook page with a red margin line - long text sits on the lines.

![Notebook](../media/notebook.png)

## Usage

```tsx
import { Notebook } from 'paperpop';

<Notebook holes>
  <h2>Was ich gelernt habe</h2>
  <p>Ein Server mit 110 Spielern zeigt dir schnell, was du noch nicht weißt. Und dass Freundschaften länger halten als jede Map.</p>
</Notebook>
```

## Props

### Notebook

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `margin` | `number` |  | Distance of the red margin line from the left (px). Default 70, 40 on small screens. |
| `line` | `number` | `36` | Line height of the ruling (px). Text snaps to it. |
| `edge` | `TornEdge` | `'top-1'` | Torn edge. |
| `tilt` | `number` | `0.6` | Rotation in degrees. |
| `holes` | `boolean` |  | Punch holes along the left edge. |
| `as` | `ElementType` | `'div'` | Rendered element, e.g. 'article'. |

Also accepts: `HTMLAttributes<HTMLDivElement>` (native attributes are passed through).

\* required
