# Newsletter

**Landing** · [all components](../../README.md#components) · animated

E-mail signup card with airmail stripes and a success stamp.

![Newsletter](../media/newsletter.gif)

## Usage

```tsx
import { Newsletter } from 'paperpop';

<Newsletter text="Einmal im Monat, was ich gebaut habe. Kein Spam." onSubscribe={async (email) => { console.log(email); }} />
```

## Props

### Newsletter

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `onSubscribe` * | `(email: string) => Promise<void> \| void` |  | Called with the e-mail address. Throw to show `errorText`. |
| `title` | `ReactNode` | `'Post von mir?'` | Headline. |
| `text` | `ReactNode` |  | Text under the headline. |
| `cta` | `ReactNode` | `'Eintragen'` | Button label. |
| `successText` | `ReactNode` | `'Du bist dabei ♥'` | Shown after success. |
| `errorText` | `ReactNode` | `'Hat nicht geklappt, versuch es nochmal.'` | Shown on error. |

Also accepts: `Omit<HTMLAttributes<HTMLFormElement>, 'onSubmit' \| 'title'>` (native attributes are passed through).

\* required
