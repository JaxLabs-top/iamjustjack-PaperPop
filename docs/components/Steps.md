# Steps

**Navigation** · [all components](../../README.md#components) · animated

Numbered torn cards in a row - "how it works" sections. They fly in one after another on scroll.

![Steps](../media/steps.gif)

## Usage

```tsx
import { Steps } from 'paperpop';

<Steps items={[
  { title: 'Repo anlegen', text: 'Template nutzen, fertig.' },
  { title: 'Komponenten wählen', text: 'Alles liegt in Paper Pop.' },
  { title: 'Seite bauen', text: 'Zusammenstecken wie Lego.' },
  { title: 'Pushen', text: 'Der Runner deployt.' },
]} />
```

## Props

### Steps

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` * | `Array<{ title: ReactNode; text?: ReactNode; color?: PaperColor; edge?: TornEdge; tilt?: number }>` |  | Steps with a handwritten title and text; colour, edge and tilt vary automatically unless set. |
| `columns` | `number` | `4` | Columns on wide screens. |
| `edge` | `TornEdge` | `'card-1'` | Torn edge for each card. |

Also accepts: `HTMLAttributes<HTMLOListElement>` (native attributes are passed through).

\* required
