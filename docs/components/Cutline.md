# Cutline

**Foundations** · [all components](../../README.md#components) · animated

Dashed "cut here" divider - click it and the scissors snip along the line.

![Cutline](../media/cutline.gif)

## Usage

```tsx
import { Cutline } from 'paperpop';

<Cutline label="hier abschneiden" style={{ margin: 0 }} />
```

## Notes

Click anywhere on the line to cut. With `onView` it cuts once by itself when it scrolls into view (the Footer does this).

## Props

### Cutline

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `ReactNode` |  | Optional handwritten note at the end of the line. |
| `onView` | `boolean` |  | Cut once by itself when it scrolls into view. Clicking always cuts. |

Also accepts: `HTMLAttributes<HTMLDivElement>` (native attributes are passed through).

\* required
