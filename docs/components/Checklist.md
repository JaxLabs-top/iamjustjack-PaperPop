# Checklist

**Apps** · [all components](../../README.md#components) · animated

To-do list on a sticky note - tick items off, optionally add new ones.

![Checklist](../media/checklist.gif)

## Usage

```tsx
import { Checklist } from 'paperpop';

<Checklist title="Heute" addable items={[
  { id: 'a', label: 'Kaffee', done: true },
  { id: 'b', label: 'Paper Pop pushen' },
  { id: 'c', label: 'Mama anrufen' },
]} />
```

## Props

### Checklist

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` * | `ChecklistItem[]` |  | Items. |
| `onChange` | `(items: ChecklistItem[]) => void` |  | Called with the updated items. |
| `title` | `ReactNode` |  | Title in marker font. |
| `color` | `PaperColor` | `'mint'` | Note colour. |
| `addable` | `boolean` |  | Allow adding new items. |
| `tilt` | `number` | `2` | Rotation in degrees. |

Also accepts: `Omit<HTMLAttributes<HTMLDivElement>, 'onChange' \| 'title'>` (native attributes are passed through).

\* required
