# Avatar

**Dashboard** · [all components](../../README.md#components)

Round avatar with image or initials (colour from the name) and status dot, plus overlapping groups.

![Avatar](../media/avatar.png)

## Usage

```tsx
import { Avatar, AvatarGroup } from 'paperpop';

<div style={{ display: 'flex', flexWrap: 'wrap', gap: 30, alignItems: 'center' }}>
  <Avatar name="Jack Feuchte" size="lg" status="online" />
  <Avatar name="Kim Berg" status="away" />
  <Avatar name="Alex" size="sm" status="offline" />
  <AvatarGroup people={[{ name: 'Kim' }, { name: 'Boby' }, { name: 'Alex' }, { name: 'Sam' }, { name: 'Lou' }, { name: 'Mo' }]} max={4} />
</div>
```

## Props

### Avatar

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `name` * | `string` |  | Full name - used for initials, colour and alt text. |
| `src` | `string` |  | Image URL. |
| `size` | `Size \| number` | `'md'` | Size. |
| `status` | `'online' \| 'away' \| 'offline'` |  | Online status dot. |
| `color` | `PaperColor` |  | Colour override (otherwise derived from the name). |

Also accepts: `HTMLAttributes<HTMLSpanElement>` (native attributes are passed through).

\* required

### AvatarGroup

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `people` * | `Array<{ name: string; src?: string }>` |  | People. |
| `max` | `number` | `4` | Max avatars shown before "+n". |
| `size` | `Size` | `'md'` | Avatar size. |

Also accepts: `HTMLAttributes<HTMLDivElement>` (native attributes are passed through).

\* required
