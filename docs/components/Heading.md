# Heading

**Foundations** · [all components](../../README.md#components)

Chunky display headings in five sizes plus the handwritten Kicker line.

![Heading](../media/heading.png)

## Usage

```tsx
import { Heading, Kicker, Marker } from 'paperpop';

<div>
  <Kicker>hi, schön dass du da bist ♥</Kicker>
  <Heading level={1} size="xl">Ich bin Jack<em>.</em></Heading>
  <Heading size="md" style={{ marginTop: 20 }}>Eine Zwischenüberschrift</Heading>
  <p style={{ marginTop: 12 }}>Fließtext in IBM Plex Mono, <span className="pp-hand" style={{ fontSize: 20 }}>Notizen in Marker</span>, <span className="pp-caps">Labels in Caps</span>.</p>
</div>
```

## Props

### Heading

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `level` | `1 \| 2 \| 3 \| 4` | `2` | Semantic level (h1-h4). |
| `size` | `'xxl' \| 'xl' \| 'lg' \| 'md' \| 'sm'` | `'lg'` | Visual size, independent from the level. |
| `accent` | `PaperColor` |  | Colour of a trailing accent like the pink dot in "Jack.". |

Also accepts: `HTMLAttributes<HTMLHeadingElement>` (native attributes are passed through).

\* required

### Kicker

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `tilt` | `number` | `-2` | Rotation in degrees. |

Also accepts: `HTMLAttributes<HTMLSpanElement>` (native attributes are passed through).

\* required
