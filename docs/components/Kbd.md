# Kbd

**Apps** · [all components](../../README.md#components)

Keyboard key caps for shortcuts.

![Kbd](../media/kbd.png)

## Usage

```tsx
import { Kbd } from 'paperpop';

<p style={{ margin: 0 }}>Suche öffnen mit <Kbd keys={['⌘', 'K']} /> oder einfach <Kbd keys="/" />.</p>
```

## Props

### Kbd

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `keys` * | `string \| string[]` |  | Keys, e.g. ['⌘', 'K']. Strings render a single key. |

Also accepts: `HTMLAttributes<HTMLElement>` (native attributes are passed through).

\* required
