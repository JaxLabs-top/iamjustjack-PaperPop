# Footer

**Navigation** · [all components](../../README.md#components)

Torn footer strip with brand, note, legal links and a scissors cut line above.

![Footer](../media/footer.png)

## Usage

```tsx
import { Footer } from 'paperpop';

<Footer
  brand="JACK"
  note="© 2026 Jack · Kein Tracking, versprochen."
  links={[{ label: 'Impressum', href: '/imprint' }, { label: 'Datenschutz', href: '/privacy' }]}
  aside={<a href="#top">nach oben ↑</a>}
  style={{ marginTop: 0 }}
/>
```

## Props

### Footer

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `brand` * | `ReactNode` |  | Big brand word on the left. |
| `note` | `ReactNode` |  | Text line (copyright etc.). |
| `links` | `FooterLink[]` |  | Small links (Impressum, Datenschutz …); entries without href become buttons. |
| `aside` | `ReactNode` |  | Right side, e.g. "nach oben ↑". |
| `color` | `PaperColor` | `'lilac'` | Sheet colour. |
| `cutline` | `boolean` | `true` | Draw a scissors cut line above the footer. |

Also accepts: `HTMLAttributes<HTMLElement>` (native attributes are passed through).

\* required
