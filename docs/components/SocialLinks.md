# SocialLinks

**Buttons** · [all components](../../README.md#components)

Small chip links for social profiles and contact channels.

![SocialLinks](../media/social-links.png)

## Usage

```tsx
import { SocialLinks } from 'paperpop';

<SocialLinks />
```

## Notes

Without `items` it shows Jack's real channels from links.iamjustjack.de (`JACK_SOCIALS`). Entries with `copy` instead of `href` copy a handle, e.g. a Discord name.

## Props

### SocialLinks

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `SocialLink[]` | `JACK_SOCIALS` | Links with icon; entries with `copy` instead of `href` copy a handle. |

Also accepts: `HTMLAttributes<HTMLUListElement>` (native attributes are passed through).

\* required
