# Washi

**Foundations** · [all components](../../README.md#components)

Strips of washi tape in several prints - stick them on polaroids, cards and notes.

![Washi](../media/washi.png)

## Usage

```tsx
import { Washi } from 'paperpop';

<div style={{ display: 'grid', gap: 22, justifyItems: 'start' }}>
  <Washi inline pattern="rainbow" width={240} tilt={-2} />
  <Washi inline pattern="pink" width={200} tilt={1.5} edge="lr-2" />
  <Washi inline pattern="dots" width={260} tilt={-1} />
  <Washi inline pattern="stripes" width={220} tilt={2} edge="lr-2" />
  <Washi inline pattern="grid" width={240} tilt={-3} />
  <Washi inline pattern="hearts" width={280} tilt={1} />
</div>
```

## Props

### Washi

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `width` | `number \| string` | `140` | Tape length (number = px). |
| `tilt` | `number` | `-4` | Rotation in degrees. |
| `pattern` | `WashiPattern` | `'rainbow'` | Print on the tape. |
| `edge` | `'lr-1' \| 'lr-2'` | `'lr-1'` | Which torn ends to use. |
| `inline` | `boolean` |  | Render in the text flow instead of absolutely positioned. |

Also accepts: `HTMLAttributes<HTMLElement>` (native attributes are passed through).

\* required
